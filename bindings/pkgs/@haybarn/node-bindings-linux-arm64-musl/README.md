# `@haybarn/node-bindings-linux-arm64-musl`

> **Part of [`@haybarn/node-bindings`](https://www.npmjs.com/package/@haybarn/node-bindings)** — install that package (or [`@haybarn/node-api`](https://www.npmjs.com/package/@haybarn/node-api)), not this one.

**[Haybarn](https://query.farm/products/haybarn/)** is a derived distribution of DuckDB from [Query.Farm](https://query.farm): the same SQL, APIs and database files, with signed releases, rebuilt and signed extensions, engine improvements, and supply-chain review built in.

This is the **Linux arm64 musl** native addon for Haybarn's [Node](https://nodejs.org/) bindings to the [DuckDB C API](https://duckdb.org/docs/api/c/overview). npm installs it automatically as an optional dependency of [`@haybarn/node-bindings`](https://www.npmjs.com/package/@haybarn/node-bindings) on matching platforms.
